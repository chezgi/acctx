# Quarterly VAT workflow

1. Review sales, purchase, credit/debit notes, and taxpayer-system evidence for the quarter.
2. Separate transactions with unresolved tax status.
3. Complete the VAT task template from traceable source rows.
4. Run `acctx validate` and `acctx calc vat` when available.
5. Reconcile the result to accounting reports and previously submitted returns.
6. Write a draft output and evidence index; do not submit automatically.
